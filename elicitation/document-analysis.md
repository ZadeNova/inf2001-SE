# **INF2001 Milestone 1: Document Analysis**

Sep 25, 2026 · @Zade

The brief yields 30 findings (F-1 to F-30). F-1 has been resolved by written clarification from the client; the other 29 are open until the stakeholder interviews. The findings that most change which use cases and classes exist are F-7 (what a job is allocated to), F-6 (how jobs enter the system), F-3 (valid crew), F-16 (what workload means) and F-8 (van management).

**Method.** The team reviewed the brief line by line against six checks: contradictions, undefined terms, missing processes, business rules with unclear edge cases, numerical constraints, and missing non-functional detail. Duplicate findings were merged. Each finding was matched to a question in the stakeholder question guide, and a new question was added where none existed (marked NEW).

Source for every finding: Aircon Retailer Project Description (2 pages). Paragraphs are counted within each heading; p.1's untitled first section is called the "opening section". Roles: MGR = Manager, DCT = Dual Certified Technician, SBT = Single Brand Technician, DRV = Driver, ITA = IT Administrator.

## **3. Findings with the biggest scope impact**

| Finding | Impact |
| ----- | ----- |
| **F-7 (what a job is allocated to)** | This decides whether Van, Crew and Roster are classes and what an Assignment links, so every allocation use case depends on it. |
| **F-6 (job intake)** | No requirement creates jobs. Without an answer, the Job class has no source and no defined attributes, and there is no Create/Import Job use case. |
| **F-3 with F-22 (valid crew)** | The crew rule is the core allocation check. The 2-person vs 3-person reading changes the qualification model and whether all 6 vans can even be staffed. |
| **F-16 with F-4 (workload)** | “Workload” drives Initial Requirements 2, 6 and 7. If it includes actual “engaged” hours, a job-completion or time-recording use case and a job status lifecycle come into scope. |
| **F-8 (vans)** | The brief makes vans a hard constraint, but no requirement covers recording them or their workshop downtime. The answer adds or removes a Van entity and its management use cases. |
