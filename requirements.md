# Software Requirements Specification

> Rules are in [AGENTS.md](AGENTS.md). Every row needs a **Source** (`Brief R<n>`, `Brief §… ¶…`, `MTG-nn` or `DEC-nn`).
> If a requirement depends on an open decision, cite that DEC and set Status to `Blocked`.

**Priority:** `Must` / `Should` / `Could` / `Won't` (MoSCoW). Brief R1–R11 are the minimum deliverable per Appendix A, so they cannot be `Won't`.
**Status:** `Draft` → `Agreed` (confirmed with a stakeholder or the team) → `Withdrawn`, or `Blocked` (waiting on a DEC).
**Verification:** how we would test this: a concrete acceptance check, measurable threshold or test method.
